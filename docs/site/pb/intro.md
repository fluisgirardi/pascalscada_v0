Diferente de outros sistemas SCADA, o PascalSCADA **não********é****uma****aplicação****onde****você****ir****á****desenvolver suas****aplicações****de****supervisão.** O PascalSCADA é na verdade, um conjunto de componentes que adicionam funções SCADA a [IDE](<https://pt.wikipedia.org/wiki/Ambiente_de_desenvolvimento_integrado>) [Lazarus](<https://www.lazarus-ide.org/>). O Lazarus é um poderoso ambiente de desenvolvimento para a linguagem Pascal que utiliza o FreePascal como compilador. Ambos são projetos de código aberto (ambos utilizam as licenças GPL e LGPL simultaneamente), ou seja, são livres para usar e modificar. O Lazarus/FreePascal contem uma rica biblioteca de componentes nativos e de terceiros, inclui um excelente designer de telas, tem um excelente depurador embutido (GDB) e consegue gerar aplicações para as mais diversas arquiteturas e sistemas operacionais. Então, por que partir do zero e desenvolver tudo isso novamente? Logicamente é mais fácil adicionar o que falta a este ambiente que é bastante completo para que esta IDE possa desenvolver aplicações HMI/SCADA. E é exatamente isto que o PascalSCADA faz!

Para usar o PascalSCADA para desenvolver suas aplicações de supervisão e necessário primeiro instalar o Lazarus em seu computador para então, acrescentar o PascalSCADA a biblioteca de componentes do Lazarus.

Logo o PascalSCADA e um framework que adiciona funções SCADA a IDE do Lazarus.
