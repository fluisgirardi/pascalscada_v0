##### Custom supervisory applications

A supervisory application built with PascalSCADA and Lazarus, from the requirements to commissioning, with the source code handed over to you.

##### What an application can have

| Feature | What it includes |
|---|---|
| Operator screens | Process overviews, animations, commands, trend charts; full screen on panel PCs and touch screens, with an [on-screen keyboard](/keyboard-manager/). |
| Alarms and events | Limit or bit alarms, acknowledgement, history and [event logging](/event-and-alarm-loggers/). |
| Recipes | A recipe library with download to and upload from the PLC ([recipe controls](/hmi-recipe-controls/)). |
| History and reports | Recording to a database (PostgreSQL, MySQL/MariaDB, Firebird, SQLite...) and reports by period, shift or batch. |
| Users and security | Login, access levels per screen and per command, a record of who did what ([security system](/security-system/)). |
| Communication | The [PascalSCADA drivers](/services-protocol-drivers/) and, if needed, a new one. |
| Integration | Publishing the data over OPC UA or MQTT to MES, ERP, the cloud or another SCADA. |

##### Project examples

* A production line supervisory system with several Siemens, Rockwell or Mitsubishi PLCs.
* An HMI on ARM Linux for a machine, replacing a proprietary panel.
* Data collection from Modbus drives, scales and instruments into a database.
* Replacing an old supervisory system (Delphi, VB6 or a SCADA with per-tag licensing) while keeping the screens the operators already know.

##### What you receive

* The installable executable and the **complete Lazarus project**, with build instructions.
* Operating documentation and the list of tags and addresses.
* Support during bench testing and commissioning.
* Fixes during the warranty period set in the proposal.

##### What we need from you

The PLC and equipment models, the PLC programs or memory map, the flowchart or the screens you have in mind, and access to a test PLC or simulator during development.
